# Dependencies

This file has moved to **[docs/installation.md](docs/installation.md)**, which
carries the per-platform instructions, the conda route and the troubleshooting
table.

The short version:

```bash
pip install ffpyplayer
```

`ffpyplayer` is the only dependency. On Linux, Tkinter also needs its system
package (`sudo apt install python3-tk` or the distro equivalent).
